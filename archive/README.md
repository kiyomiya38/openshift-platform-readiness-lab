# Archive

このディレクトリには、現在の実務学習コンテンツへ再編する前の資料を保存しています。

## 収録内容

- [`personal-readiness/`](personal-readiness/)：旧版の面談準備、経歴境界、個人学習計画、技能証跡管理
- [`exercises/`](exercises/)：旧版の課題形式ラボ、質問、模範回答

これらは履歴保存用であり、現在の学習導線、製品手順、技能評価には使用しません。現在の入口はリポジトリ直下の [`README.md`](../README.md) です。

アーカイブ内の文書には旧ディレクトリ構成へのリンクや、再編前の状態表現が残る場合があります。技術情報を参照するときは、現行の `docs/`、`reference/`、`projects/` を優先してください。
