# 前回面談で共有された期待事項の匿名要約

## この文書の扱い

この文書は、前回面談で共有された内容を、個人名、組織名、顧客名、業界、案件規模、発言時刻を除いて技術要件へ要約したものです。生の発言を引用した議事録ではありません。

また、面談時点で特定案件への参画が確約されたものではありません。OpenShift 周辺技術へ継続的に対応できる人材を想定した、知識・経験・行動特性の整理として扱います。

## 全体像

特定案件へ即時投入できる OpenShift 熟練者だけを対象とするのではなく、既存の基盤知識を土台に習熟度を上げ、将来的に OpenShift 周辺案件へ継続して関われる人材が想定されていました。

製品知識だけでなく、次の二点が特に重要だと整理しています。

1. 基盤案件を要件整理、設計、構築、試験、移行、運用引き継ぎまで成果物とレビューを通して進める力
2. 未知の技術や障害に対し、観測事実から仮説を立て、自ら調査・試行・記録・報告する力

## 基盤案件で期待される進め方

OpenShift のコマンドを知っていることと、基盤案件を進められることは別です。次の流れを説明し、担当範囲では成果物と確認結果を残すことが期待されます。

```text
要求・制約の整理
  → 基本設計
  → 詳細設計・パラメータ設計
  → 構築手順と切り戻し準備
  → 構築
  → 単体・基盤結合試験
  → 移行・システムテスト支援
  → 運用引き継ぎ
```

各工程では、未確定事項、判断根拠、レビュー結果、変更履歴を残します。未経験の作業は単独で判断せず、対象バージョン、権限、影響範囲、確認先を明確にして進めます。

## 自走調査力の定義

「自走」は、分からない状態で独断実施することではありません。次の行動を指します。

1. 症状、発生時刻、変更点、影響範囲を事実として集める。
2. アプリケーション、OpenShift / Kubernetes、OS、ネットワーク、ストレージ等の層に分ける。
3. 参照系コマンドから確認し、仮説と期待結果を明記する。
4. 公式資料、既知情報、許可された AI 等を使って候補を絞る。
5. 変更が必要なら影響、承認、退避、切り戻しを確認する。
6. 分かったこと、分からないこと、試したことを整理してエスカレーションする。

## AI 利用時の情報管理

AI は一般的な製品仕様やエラーの調査を補助できますが、利用可能な環境と入力可能な情報は案件ごとに異なります。顧客名、個人情報、IP アドレス、ホスト名、ログ、認証情報、構成情報等を許可なく入力しません。

AI の回答は参考情報であり、最終判断の根拠にはしません。対象バージョンの公式資料、サポート条件、実機の状態、組織の規程で確認します。

## 自主的に追加した領域

次の領域は、面談で明示された中心要求そのものではなく、関連知識の補強または将来テーマへの備えとして、このリポジトリ側で追加したものです。

| 自主追加領域 | 追加理由 | 面談要求との境界 |
| --- | --- | --- |
| KVM / QEMU / KubeVirt の詳細 | OpenShift Virtualization の内部構成を理解するため | Virtualization と VM 移行は明示領域だが、内部実装の詳細まで直接要求されたとは扱わない |
| MTV の詳細手順 | VM 移行の評価・計画を具体化するため | VM 移行は明示領域だが、特定ツールの実施経験要求とは扱わない |
| Airgap / Disconnected Install | 閉域基盤で必要になり得る設計観点を補うため | 前回面談の明示要求には含めない |
| OpenShift AI | AI 基盤との将来的な接点を整理するため | Kong の AI Gateway と区別し、前回面談の明示要求には含めない |
| Storage / ODF、監視・ログ・バックアップの詳細 | OpenShift 基本設計と障害調査を支えるため | 個別製品の導入経験要求ではなく、基盤横断知識の補強とする |

これらを学んでも、面談側から要求された事実や商用経験としては表現しません。

## 評価時に区別すべき経験

| 区分 | 確認すること |
| --- | --- |
| 商用経験 | 実案件の責任範囲、成果物、承認・レビュー、変更管理、運用影響 |
| 教材・検証 | 使用環境、本人が行った操作、期待値と実測値、再現性、制約 |
| 概要理解 | 本人が自分の言葉で目的・構成・主要論点を説明できるか |
| 未経験 | 実施していないことを明示し、確認方法と支援が必要な範囲を説明できるか |
| 未レビュー初稿 | AI 支援等で資料が存在するだけで、本人の理解・経験には数えない |
