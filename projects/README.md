# OpenShift実務成果物サンプル

このディレクトリは、インフラストラクチャの実務経験がありOpenShift案件へ初めて参加するエンジニアを対象に、要求整理から運用引き継ぎまでで扱う成果物のつながりを示す一般公開用サンプルです。

| プロジェクト | 収録範囲 | 成果物状態 |
| --- | --- | --- |
| [Enterprise OpenShift 4.22基盤導入](enterprise-openshift-platform/README.md) | 要件、設計、構築、試験、障害対応、Virtualization / MTV、移行、運用、管理 | 架空案件／Draft／未レビュー／未承認／実機作業はすべてNot Run |

各プロジェクトは、実務で使用される文書・設定例・管理記録を番号順に配置しています。知識問題や採点課題ではなく、成果物が「どの入力を受け、何を決め、どの後続工程へ渡すか」を本文と相互リンクで解説します。

記載された組織、構成値、日程、役割はすべて架空です。実案件へ適用する際は、対象環境、契約、組織標準、製品互換性、変更承認に合わせて再設計してください。
