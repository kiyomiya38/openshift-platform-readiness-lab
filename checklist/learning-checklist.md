## 状態の付け方

| 状態 | 完了条件 |
| --- | --- |
| 未着手 | 本人による確認記録がない |
| 読了・要点整理 | 本文を確認し、要点と不明点を自分の言葉で記録した |
| 机上演習 | 自分の言葉で設計、調査報告、説明回答を作成した |
| 実機検証 | 許可された環境で期待値と実測値を記録した |
| レビュー済み | 第三者または明示した自己レビューの指摘と反映を記録した |

経験区分の「商用経験 / 教材・検証 / 概要理解 / 未経験」と、上記の進捗状態は別に管理します。
