# 検証計画

> [!IMPORTANT]
> **状態:** 計画様式準備済み / 本人による計画確定前 / 実機検証未実施
>
> 本書は検証予定を管理するもので、検証結果ではありません。実施後の記録は [証跡索引](../evidence/README.md) から参照できる場所へ保存します。

## 検証の目的

技術資料を読んだ状態と、本人が再現・説明できる状態を分けて確認します。実機操作は、破棄可能または明示的に利用許可された検証環境に限定します。

## 共通実施条件

- 対象環境、Context、利用者、権限、Namespace / Project を作業前に確認する。
- 製品と Client のバージョン、利用する Image、外部接続条件を記録する。
- 変更対象、期待結果、中止条件、Cleanup、復旧方法を実行前に定義する。
- 参照系コマンドで初期状態を保存してから変更する。
- 顧客情報、個人情報、内部 FQDN・IP、認証情報、Secret、秘密鍵を記録しない。
- 参考回答の出力を実測値として転記しない。
- 予期しない対象、権限、影響を検出した場合は中止する。

```markdown
- 対象環境 / バージョン:
- Context / Project:
- 必要権限:
- 参照する公式資料:
- 変更対象:
- 変更しない対象:
- 前提条件:
- 期待結果:
- 中止条件:
- Cleanup / 復旧方法:
- 取得する証跡:
- 機密情報の除外方法:
- 実測結果: 実施後に記入
- 差異・考察: 実施後に記入
- 証跡リンク: 実施後に記入
- 第三者レビュー: 未実施
```

## 証跡の最低要件

| 項目 | 必須内容 |
| --- | --- |
| 識別 | 検証 ID、テーマ、実施日 |
| 再現条件 | 環境種別、製品・Client バージョン、権限、前提 |
| 操作 | 実際に実行したコマンドまたは記入した成果物 |
| 判定 | 事前に定めた期待結果と合格条件 |
| 結果 | 実測値、Pass / Fail / Blocked / Not Run |
| 考察 | 差異、原因仮説、追加確認、次の行動 |
| 安全 | 後処理、機密情報の除外、影響範囲 |
| レビュー | 確認者、指摘、反映結果。未実施なら未実施と明記 |

## 提出前ゲート

- [ ] `Not Run`、`Blocked`、参考回答を `Pass` に数えていない
- [ ] README と learning-report の実施状況が証跡索引と一致する
- [ ] 本人が説明できない成果物を提出実績としていない
- [ ] 商用経験と教材・検証の境界が一貫している
- [ ] 製品バージョン依存の記述を公式資料で再確認した
- [ ] 機密情報、個人情報、内部環境情報を除外した
- [ ] 外部共有対象と自己練習用資料を区別した
