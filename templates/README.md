# 実務文書テンプレート

このディレクトリには、記入済みの成果物例を組織の正式様式へ転記する際に使う空テンプレートを収録しています。完成済み成果物、実行記録、試験実績を示すファイルではありません。

## 利用原則

1. 組織、顧客、案件で指定された正式様式があれば、そちらを優先する。
2. 記入済み成果物例から必要な判断、粒度、トレーサビリティを確認する。
3. `<記入>`、`<要確認>`、例示値を案件固有の承認済み情報へ置換する。
4. 要件 ID、設計 ID、変更 ID、課題 ID、試験 ID を文書間で対応させる。
5. 作成者、レビュー担当、承認者、版、更新日、変更理由を記録する。

Secret、Token、Cookie、pull secret、秘密鍵、実 kubeconfig は記載しません。機密値は承認済み Secret 管理システムの参照 ID だけを記載します。未実施の作業・試験は実績として記録せず、`NOT RUN` または組織標準の未実施状態を使用してください。

## 記入後の確認

- 対象環境と OCP 4.22 の正確な z-stream が明記されている。
- `要確認` に担当と期限があり、推測が確定事項として書かれていない。
- 操作の期待結果、中止条件、ロールバック、事後確認が対応している。
- 期待値と実測値、計画と実績が分離されている。
- 組織の版管理、レビュー、承認、機密情報取扱いに適合している。
