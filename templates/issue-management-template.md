# OpenShift 課題管理表

> 障害（発生済み事象）、リスク（未発生の可能性）、課題（判断・作業が必要）を区別する。機密値は記録しない。

## 運用ルール

- Priority: `P1`（停止・重大影響）、`P2`（主要機能影響）、`P3`（限定影響）、`P4`（改善）。案件定義は要確認。
- Status: `New / Investigating / Action / Waiting / Resolved / Closed`。
- 口頭で閉じず、根拠、確認者、日付を残す。
- 顧客名、IP、ログは必要に応じマスキングし、詳細証跡はアクセス制御先へ置く。
