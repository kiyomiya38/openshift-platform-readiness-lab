## 2. 合否・中止基準

- Pass: 実績が期待結果を満たし、重大な未解決課題がない。
- Fail: 期待結果を満たさない。事実と証跡を課題 ID へ関連付ける。
- Blocked: 前提不足で未実施。Fail と混同しない。
- 中止条件: `<本番影響、データ損失懸念、重大アラート等>`
